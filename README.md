# 체험단 일정

폰 홈 화면에 설치해서 쓰는 체험단 일정 관리 웹앱입니다.

- 사진 캡처를 올리면 기기 안에서 글자를 읽어 항목을 채웁니다 (Tesseract OCR).
- 데이터는 브라우저에 저장됩니다. 기기 간 이동은 "백업 저장 / 백업 불러오기"를 쓰세요.
- 코드를 `main`에 올리면 자동 배포되고, 설치한 앱에 "새 버전이 있어요" 알림이 뜹니다.

설정: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꿔야 합니다.
새 버전을 배포하면 설치한 앱에 업데이트 알림이 뜹니다.
